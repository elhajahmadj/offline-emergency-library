🛟 Offline Emergency Kit — START HERE

This drive is a self-contained offline survival library + AI. Everything works with

no internet. This page explains what's here and how to open each part.

🆘 In an emergency right now? Open I need to… — a task-first index that sends you straight to the right file for bleeding, CPR, water, calling for help, navigation and more.
🖨️ Before the battery dies: print Emergency essentials — one page of the most critical reminders (bleeding, CPR, water, signalling, frequencies) that works on paper with no power.
How this kit is meant to be used: the books, manuals and maps are the authority. The offline AI is a fast assistant: it helps you find and digest the library - search it, summarize it, cross-reference it. For anything safety-critical (medical doses, water treatment, first-aid steps), read the manual itself and follow it.
Windows vs macOS/Linux: launchers are .bat files on Windows and .sh files on macOS/Linux (run them from a terminal). The content, PDFs, HTML guides, and phone apps are identical on every platform.
Three ways to read and use things on this drive: - PDFs and these guides (.html) open in Edge or any web browser — no software. - .zim archives open in Kiwix (portable, no install) — see E:\Kiwix-Reader\. - Ask questions of the bundled docs = Ask the manuals - run AI-Offline\Manual-QA\START-DOCS.bat (start-docs.command on macOS, start-docs.sh on Linux), then open http://127.0.0.1:8081/AI-Offline/Manual-QA/. GPT4All LocalDocs can also index folders of your own files.

Windows vs macOS/Linux: the chat / Web-UI / translator launchers, OPEN-MAPS and CHECK-DRIVE ship in both forms on every drive — .bat on Windows and .sh on macOS/Linux (run them from a terminal); macOS also gets CHECK-DRIVE.command for a double-click. VIEW-MAPS-ON-PC is the exception: it's written in just one form, matching the OS that built the drive — .bat on a Windows-built drive, .sh on a macOS/Linux-built one. Quick start by need

  • Prepare for a dead battery: print EMERGENCY-ESSENTIALS.html (one page of critical reminders) and your region's map now, while you have power.
  • Navigate without a device: open OsmAnd\MAP-AND-COMPASS.html and print it while preparing the kit. Keep a paper topographic map and compass.
  • Keep a device charged off-grid: read Power and devices for battery sizing, solar/car charging and low-power reading setups.
  • I want to chat with an AI offline: AI-Offline\ → double-click CHAT-3B-light.bat (great for brainstorming and summaries; for anything safety-critical, follow the manuals).
  • I want the AI to answer from my manuals - recommended for medical & survival questions: open AI-Offline\Manual-QA\START-DOCS.bat (start-docs.command on macOS, start-docs.sh on Linux), then open http://127.0.0.1:8081/AI-Offline/Manual-QA/ and ask. The page shows the passages it used and links each one to the PDF, so you can check them. No setup or internet is needed.

⚠️ Reminders

  • Offline AIs and old manuals can be wrong. Use the AI to find and summarize; for anything safety-critical, read the manual itself and follow it.
  • Keep the drive backed up (a second copy on another drive/USB is wise), and run CHECK-DRIVE (CHECK-DRIVE.bat on Windows, CHECK-DRIVE.command on macOS) every few months to find damaged files.
  • Practice using each tool now so it's familiar in an actual emergency.

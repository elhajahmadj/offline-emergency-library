- **One component table as data (`components.tsv`).** A single list of what the kit downloads — one row per component with its license, license link and upstream source, keyed to the piece ids in `catalog.json` (which already owns each piece's installer flag, presets and size). A new CI check (`check-components.sh`) fails the build if any row is missing a license, a license link or a source, or names a piece that is not in `catalog.json` — so a source can no longer be added unlicensed.

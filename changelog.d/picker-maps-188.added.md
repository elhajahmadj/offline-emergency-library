- **Point-and-click picker (Maps).** A static `web/index.html` lets you tick map regions (continents, countries, or drill into all 50 US states), search them, and export a `selection.json` the installers already understand (`--select` / `-Selection`). The page shows sizes and flags any catalog "needs" rule before you export, works from `file://` with no server or internet, and loads the catalog as `web/catalog.js` (generated from `catalog.json`; a CI check keeps them in sync). The launchers (`install.bat`, `install.command`, new `install.sh`) now offer "pick what to install" — they open the page, pick up the newest `selection.json` from Downloads, preview it, and install on confirmation. _[@elhajahmadj](https://github.com/elhajahmadj) - PR #PENDING._

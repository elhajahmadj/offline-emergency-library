- **Running the Windows installer now reliably opens the picker page in a browser — on both choices.** Before, the browser only opened on `[P] Pick`, and even then `start "" web\index.html` silently did nothing when `.html` had no default app (or was set to an editor), so the page never appeared. Now `install.bat` opens the picker on `[A] Install everything` / the default too, and uses a robust open that launches an installed browser directly (Chrome, Edge — which ships with Windows 10/11 — then Firefox), then the default handler, then the URL protocol handler, printing an "open it by hand" path only if everything fails. _[@elhajahmadj](https://github.com/elhajahmadj) - PR #214._

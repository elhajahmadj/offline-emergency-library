- **The phone-pack builder no longer spends ~2 minutes retrying a dead link.** `build-phone-pack.py`'s downloader used `curl --retry-all-errors`, which retried permanent HTTP 4xx the same as a transient blip, so a source that was really gone took six retries to fail. It now fails fast on a 4xx (with the URL in the error) while still riding out timeouts, 5xx and the TLS connection drops archive.org hands CI runners.
